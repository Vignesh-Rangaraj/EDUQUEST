## Source and scope

The figure content follows the manuscript's figure descriptions and nearby prose. The diagrams are generated by `generate_diagrams.py`; rerun it with Python and Pillow installed to recreate both formats.

Fig. 5 shows the source-verified Tutor path: CHAT, EXPLAIN, SIMPLIFY, HINT, and PRACTICE modes; six response languages; optional Activity and LessonContent context; backend Gemini requests and chat persistence; and browser speech support. PRACTICE can ask Gemini for a few practice questions, but the source does not expose a teacher quiz-generation workflow. No lesson-summarization or teacher analytics assistant workflow was found.

`revise_ai_manuscript.py` takes a source DOCX, output DOCX, and the compact IEEE PNG. It revises AI-related prose and the table entries, then replaces the existing Fig. 5 image while leaving the input manuscript untouched.

## Manuscript consistency points to resolve before submission

- Section IV calls the design “five cooperating layers” but then enumerates Client, Offline Storage, Synchronization, Transport, Backend, and Persistence: six layers. Fig. 1 shows all six named layers.
- Fig. 5's original caption/prose presented four Gemini features, while source verification confirmed the AI Tutor flow only. The revised copy limits its claims to the implemented Tutor and its browser voice controls.
- Section IV names four roles, whereas Table I refers to five roles. This is outside the figure scope but should be reconciled in the paper.
- Fig. 3 follows the manuscript's 14-entity core scope. The production schema contains other entities, and several links in this figure are logical `*_id` associations rather than JPA relationship annotations.
- The gamification formulas and six-stage journey shown in Fig. 4 are transcribed from the manuscript. The figure does not claim that every game format uses the same scoring rule.

## Visual validation

All five figures were rendered from the editable source and inspected at presentation scale. The compact IEEE variant is sized for the manuscript's existing 3.35-inch figure column. They use a white background, high-contrast labels, and scalable vector originals for editing or publication layout.
